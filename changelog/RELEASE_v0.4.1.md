# Release v0.4.1

**Released:** 2026-10-19
**Previous version:** v0.4.0

A small polish release for the admin. List rows and the photo cropper now use icon buttons in place of text ones.

## Improvements

- **Icon buttons in list editors.** Move up, move down and delete are now 44px icon buttons (chevrons and a bin), with tooltips. On phones they sit at the end of the row instead of stretching across it. On wide screens the actions column is narrower, which gives the fields more room. Screen readers announce the same names as before, for example "Delete track 1".
- **Icon zoom buttons in the photo cropper.** Zoom in and zoom out are magnifier icons with the same accessible names.

No API changes.
